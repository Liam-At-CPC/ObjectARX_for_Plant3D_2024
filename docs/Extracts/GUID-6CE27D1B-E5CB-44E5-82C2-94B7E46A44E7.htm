Plant 3D and P&ID Managed Classes

 
 
 

Managed wrappers are provided for the P&ID and Plant 3D entity classes listed in the Plant SDK2024: Developer Reference (plantsdk_ref.chm), enabling developers to write applications in any language that is supported by the Microsoft .NET Framework. Project and Data manager SDK class libraries are directly available only as managed classes.

In situations where a choice can be made, use of the .NET managed API is recommended.
