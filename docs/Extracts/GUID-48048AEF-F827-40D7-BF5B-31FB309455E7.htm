AcPpTagFormat

 
 
 

AcPpTagFormat is a helper class derived from AcDbObject. It is used to store format strings that are assigned to an entity such as a simple annotation (AcDbText) into the drawing database.

When you copy a component or line, the new item is assigned a temporary tag that contains a question mark to differentiate it from the original tag. For example, if the original tag for a piece of equipment is P-100, the temporary tag might be ?-100.
