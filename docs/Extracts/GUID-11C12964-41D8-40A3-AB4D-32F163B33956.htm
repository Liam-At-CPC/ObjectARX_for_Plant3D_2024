Project Properties

 
 
 

Project properties are available through the managed Project class.

The following code lists all of the Autogen properties currently active in a project. 

public static void PnPListAutogen()
{
   public static void PnPListAutogen()
   Project oProject = PnPActiveProject();
   if (oProject == null) return;
   Database oDwg =    AcadApp.DocumentManager.MdiActiveDocument.Database;
   oProject.GetDrawingAutogenProperties(oDwg.Filename);
   oEditor.WriteMessage("\nAutogen Values");
   StringCollection asKeys;
   oProject.GetAutogenPropertyKeys(true, out asKeys);
   foreach (String sKey in asKeys)
   {
      int nLastUsed, nIncrement;
      oProject.GetProjectAutogenPropertyValue(sKey, out nLastUsed, out nIncrement);
      oEditor.WriteMessage("\n   " + sKey + ": " + "Last (" + nLastUsed + ") Increment (" + nIncrement + ")");
   }
}
