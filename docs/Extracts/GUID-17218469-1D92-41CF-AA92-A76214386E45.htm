Datalinks Manager

 
 
 

The Datalinks Manager manages links between objects in AutoCAD drawings and rows in the project data cache that contain non-graphical properties for the objects. You acquire the PnPDatabase from the Datalinks Manager.

Each AcDbObject can be linked to only one record in the project data cache. However, a project data cache record can be associated with multiple AcDbObjects.

For example, when two off-page connectors are connected, the line entities in each drawing are both linked to a single record in the project data cache.

The following code illustrates how to retrieve the current Datalinks Manager by name: 

//C++
AcPpDataLinksManager* getCurrentDataLinksManager()
{
   // Use services to get the data links manager name for this project
   AcPnIDServices* pServices = AcPnIDServices::getPnIDServices();  
   AcPpDataLinksManager* pLm = NULL;       
   
   TCHAR projectName[4096]; 
   projectName[0] = ACRX_T('\0');
   if (pServices != NULL)
   {    
      pServices->getDataLinksManagerName(projectName, 4096);   
      // Get the correct data links manager based on the name.   
      EPpDLStatus dlStat = AcPpDataLinksManager::GetManager(projectName, pLm);
   }
}

The following .NET managed code illustrates how to obtain the Datalinks Manager and PnPDatabase for active project part. 

//C#
Project prj = PnPProjectUtils.GetProjectPartForCurrentDocument();
DataLinksManager dlm = prj.DataLinksManager;
PnPDatabase db = dlm.GetPnPDatabase();

The following .NET managed code illustrates how to obtain a PnPDatabase without using the Datalinks Manager. This is useful in a stand-alone program. 

//C#
PnPDatabase db = PnPDatabase.Open("C:\\SampleProject\\ProcessPower.dcf");

The following .NET managed code illustrates how to obtain the Datalinks Manager for the current drawing. The data linked to the drawing is read-only and pending a save (DrawingHasBlob). In most situations you would use the Datalinks Manager from the Project Database. 

//C#
Database db = Application.DocumentManager.MdiActiveDocument.Database;
DataLinksManager dlm = DataLinksManager.GetManager(db);
