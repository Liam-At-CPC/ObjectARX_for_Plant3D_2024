Annotation

 
 
 

This class (Annotation, AcPpAnnotation) is a utility class used to create and maintain annotation entities.

To base a style on a template, use AnnotationTemplates, and select a block definition from that drawing. The template block definitions contain dynamic block parameters that allow the annotation to dynamically size based on the evaluated size of the text when the annotation is placed in the drawing. 

//C#
Database db = Application.DocumentManager.MdiActiveDocument.Database;
Editor ed = Application.DocumentManager.MdiActiveDocument.Editor;
ObjectId annotationId = ed.GetEntity("Pick Annotation: ").ObjectId;
Annotation an = new Annotation(annotationId);
for (int ifs=0; ifs<an.NumFormatStrings; ifs++) {
   String sfs = an.GetFormatString(ifs);
   ObjectId targetId=an.TargetId;
   FormatToolsUtil oUtil=new FormatToolsUtil();
   //Evaluate
   String seval = oUtil.Evaluate(sfs, targetId);
   ed.WriteMessage(seval +" ("+ sfs + ").");
}

The code above illustrates managed use of the Annotation and the AnnotationFormatToolsUtil class.
