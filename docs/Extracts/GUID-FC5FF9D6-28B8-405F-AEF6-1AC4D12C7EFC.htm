API Architecture (P&ID)

 
 
 

Similar to the layout of the P&ID user interface, the Plant SDK API is organized into three main components: Drawing Entities, the Plant Project, and the Data Manager.

  • Drawing Entities and Objects. The schematic entities and supporting objects that are customized for AutoCAD P&ID.
  • Project API. Used to control and define the Files and Settings that make up a Plant Project.
  • Data API. Used to access and extend asset properties and project-wide link relationships.
NOTE:The Project Manager and Data Manager API is not exposed directly to unmanaged applications. ARX applications that need access to this functionality should use C++ interop to access the .NET managed CLR. A sample application (ProjectList) is provided with the Plant SDK.
