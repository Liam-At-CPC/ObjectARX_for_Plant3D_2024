Line Segments

 
 
 

The line segment (LineSegment, AcPpLineSegment) class represents the schematic line entity in AutoCAD P&ID. Both signal lines and pipelines are P&ID LineSegments.

Each segment is similar to an AutoCAD polyline, containing additional information such as flow direction, tag number, and line size.

NOTE:Individual P&ID sline entities are segmented by their functional connections, and not their geometric direction changes. An individual LineSegment contains two or more vertices similar to LWPOLYLINE entities.

The standard AutoCAD GROUP command allows users to identify individual entities that are to be treated as a single object when selected. The concept is similar with P&ID line groups. LineGroups in AutoCAD P&ID are strictly and automatically managed in order to maintain the connective integrity of a pipeline.

All LineSegements belong to exactly one LineGroup.
