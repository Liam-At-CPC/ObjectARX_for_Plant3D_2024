The Plant SDK Developer API extends the AutoCAD API. P&ID-specific features are available as extensions to ObjectARX and the ObjectARX managed wrappers for .NET. Both of these require Microsoft Visual Studio.

NOTE:The Plant SDK requires AutoCAD 2024 ObjectARX. AutoCAD 2024 ObjectARX may be found at https://www.autodesk.com/developer-network/platform-technologies/autocad.

Microsoft Visual Studio requirements and setup are described in Getting Started from the ObjectARX Developer Guide (arxdev.chm).
