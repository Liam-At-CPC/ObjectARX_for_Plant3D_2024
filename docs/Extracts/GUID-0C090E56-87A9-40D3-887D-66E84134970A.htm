C++ interop

 
 
 

DataObjects and ProjectManager classes are available directly only as managed classes. To access the functionality of these classes, application developers will need to access the .NET common language runtime (CLR).

C++ interop is enabled with the /clr (Common Language Runtime Compilation) compiler switch. When enabled, the #using directive is available to reference managed assemblies.

NOTE:The C++ interop mechanism is frequently called It Just Works (IJW).

A sample is provided in the PnPSDK to illustrate how to call functions in the .NET ProjectManager namespace from an unmanaged ObjectARX application.

The sample application ProjectList is written in unmanaged C++ and is installed with the SDK. ProjectList illustrates how to access the Project class within the Autodesk.ProcessPower.ProjectManager managed namespace.

It is not necessary to compile all modules of an ObjectARX application with /clr. The ProjectList sample uses Common Language Runtime compilation only for ProjectListClr.cpp. All other modules do not compile with /clr. Additional compiler settings were adjusted as follows for ProjectListClr.cpp:

Basic Runtime Checks was set to Default. Enable Minimal Rebuild was set to No. Enable C++ Exceptions was set to Yes With SEH Exceptions (/EHa). Debug Information Format was set to Program database (/Zi).

NOTE:To debug the sample, the Debugger Type should be set to Mixed in the Visual Studio project.

The following code is based on the ProjectList sample. It obtains project drawing names as simple unmanaged strings by iterating through managed PnPProjectDrawing objects using C++ interop. 

//C++/CLI
#using <PnPProjectManagerMgd.dll>
using namespace Autodesk::ProcessPower::ProjectManager;
using namespace Autodesk::ProcessPower::PlantInstance;
   
Project^ pProject = PlantApplication::CurrentProject->ProjectParts[L"PnId"];
for each (PnPProjectDrawing^ pDwg in pProject->GetPnPDrawingFiles()) 
{
   const wchar_t *sProjectDwgName = StringToWchar(pDwg->ResolvedFilePath);
}

ObjectARX provides StringToWchar, which is defined mgdinterop.h.
