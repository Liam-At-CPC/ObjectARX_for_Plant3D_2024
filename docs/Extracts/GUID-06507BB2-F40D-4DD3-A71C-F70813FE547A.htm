ObjectARX Sample

 
 
 

A sample project using C++ is installed with the SDK. The project name is PnpScanValves.

The sample project links to PnIDObjects.lib and AcPnpDataLinks.lib.

The following code block from the sample project illustrates how to collect and iterate through all of the schematic line segments in the drawing. Error checking is removed for clarity. 

//C++
AcDbObjectIdArray arrLineSegment;
LoadLineSegments(arrLineSegment); //Sample function to collect sline id’s.
for(int i = 0; i < arrLineSegment.length(); i++) {
   AcDbObjectPointer<AcPpLineSegment> pLine(arrLineSegment[i], AcDb::kForWrite); 
   AcPpLineObjectIterator *it = pLine->lineObjectIterator(NULL);
   for (it->start(); !it->done(); it->step()) {
      AcPpLineObject *pLineObj = it->object();
      AcDbObjectId oValveId = ((AcPpInlineObject*)pLineObj)->objectId(); 
   }
   delete it;
   pLine.close();
}

Building the project produces PnPScanValves.arx. Use the ARX command to load the extension, which will define the SCANVALVES command. This command function scans through all the valves (under the class "HandValves"), sorts them by location, and applies a seeded incremental numeric suffix to each tag.
