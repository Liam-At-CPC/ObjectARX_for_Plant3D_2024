PpRowId

 
 
 

AcPpRowId is an identifier for a P&ID object’s record in the PnP Database.

NOTE:AcPpRowId is not a class, it is scalar, type long. The .NET managed assembly does not define PpRowId, and simply uses long. When exchanged as a collection, the PnPRowIdArray type is used.

Use FindAcPpRowId of the DataLinksManager to retrieve the data row ID from an AcPpObjectId. Provided with the AcPpObjectId of a P&ID entity, the following code acquires the AcPpRowId: 

//C++
AcPpObjectId pnpId;
AcPpDataLinksManager* dlm;
//Initialize pnpId and dlm
   
AcPpRowId rid;
dlm->FindAcPpRowId(pnpId, rid);

AcPpRowIdArray is used by AcPpDataLinkManager functions that accept, or provide multiple row IDs. For example, SelectAcPpRowIds can provide an array of row IDs for all items in the drawing.
