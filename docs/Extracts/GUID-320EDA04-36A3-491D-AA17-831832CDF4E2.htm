Role and Relationship Types

 
 
 

Relationships and Roles are string parameters. For example "PartPort" is a relationship of roles "Part" and "Port"). The roles are relationship-specific, so you must match up the roles with appropriate relationships. The following code lists all relationjships and roles in a project. 

public void ListRelationships()
{
    Editor ed = Application.DocumentManager.MdiActiveDocument.Editor;
    Project prj = PnPProjectUtils.GetProjectPartForCurrentDocument();
    DataLinksManager dlm = prj.DataLinksManager;
    PnPDatabase db = dlm.GetPnPDatabase();

    PnPRelationshipTypes relTypes=db.RelationshipTypes;
    foreach (PnPRelationshipType relType in relTypes)
    {
        ed.WriteMessage("\nPnPRelationshipType: " + relType.Name+"\n");

        //Roles
        PnPRoleTypes roles = relType.RoleTypes;

        //Properties
        PnPRelationshipProperties relprops = relType.Properties;
        PnPRelationship[] rels = relType.Select();

        //Relationships
        foreach (PnPRelationship rel in rels)
        {
            //Roles
            foreach (PnPRoleType role in roles)
            {
                int id = rel[role];
                PnPRow relrow = db.GetRow(id);
                ed.WriteMessage("  " + role.Name + "=" + relrow.ClassName);
            }
            //Relationships Properties
            PnPRelationshipPropertyValues relpropvals = rel.PropertyValues;
            foreach (PnPRelationshipProperty relprop in relprops)
            {
                ed.WriteMessage("  " + relprop.Name + "=" + relpropvals[relprop].ToString());
            }
            ed.WriteMessage("\n");
        }
    }
}

Each relationship has two roles that are interchangeable, depending on the information you are interested in finding. For example, LineStartAsset is the relationship between a line and the start asset of the line.

You can use “Line” as role 1, and pass in a line’s ID, and use “Asset” as role 2. The result is the ID of the asset. The reverse is also true; you can specify “Asset” as role 1, and pass in the asset’s ID, and use “Line” as role 2. The line’s ID is provided.

The following code comments the creation of a LineFlowArrow relationship: 

//C++
// pLm is the pointer to AcPpDataLinksManager class
pLm->Relate(ePpRTLineFlowArrow, ePpRoleArrow, flowArrowId, ePpRoleLine, lineId);
   
// ePpRTLineFlowArrow is the relationship being used.
// ePpRoleArrow is the arrow role being used as role 1.
// flowArrowId is the object id of the flow arrow entity.
// ePpRoleLine is the line role being used as role 2.
// lineId is the object id of the SLINE entity.

Similarly, an AssetOwnership relationship is created by the following: 

//C++
pLm->Relate(ePpRTAssetOwnership, ePpRoleOwner, ownerId, ePpRoleOwned, ownedId);
   
// ePpRTAssetOwnership is the relationship being used.
// ePpRoleOwner is the owner role being used as role 1.
// ownerId is the object id of the entity acting as the owner.
// ePpRoleOwned is the owned role being used as role 2.
// ownedId is the object id of the entity that is owned (e.g. child)

The following code sample shows how to relate two selected items into an AssetOwnership relationship : 

//C#
Database db = Application.DocumentManager.MdiActiveDocument.Database;
DataLinksManager dlm = DataLinksManager.GetManager(db);
Editor ed = Application.DocumentManager.MdiActiveDocument.Editor;
ObjectId entId1 = ed.GetEntity("Pick owner: ").ObjectId;
ObjectId entId2 = ed.GetEntity("Pick owned: ").ObjectId;
   
//Set relationship
dlm.Relate("AssetOwnership", "Owner", entId1, "Owned", entId2);
