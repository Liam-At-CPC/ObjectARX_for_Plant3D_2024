Format Strings

 
 
 

Format strings can contain codes that are evaluated to recover property values, to apply formatting, or to introduce automatically generated numbers.

An evaluation sequence is contained within a pair of parentheses that are prefixed with a hash (#) character.

Format strings contain syntax that can represent information about the project, drawing, and item with which they are associated. These values are prefixed with the hash character and take the following form: 

#(Project.
 category
.Property) #(Drawing.

 category
.Property) #(

 class
.Property)

where class is frequently TargetObject and category is General.

Any name that appears within the parentheses is to be replaced with a value from the project, drawing, or item context. Example: #(TargetObject.Tag).

Certain characters within the parentheses have special meaning, and cannot be part of a name.

The percent character (%) prefixes a format sequence. The at sign (@) prefixes a numeric format sequence, which is replaced by an automatically generated value.

Sequence-incrementing characters dollar sign ($) and caret (^) are associated with a field name. The caret (^) updates the field with the next sequence value after evaluation.

A question mark (?) indicates user input is requested.

An equal sign (=) can be used to prefix a name for the second line (mate) of an Off Page Connector.

Sequence-formatting characters include: (A) for an upper-case character, (a) for any character (upper case and lower case), and (N) to represent a digit. Numeric formatting can contain a period (.) for fractional format.

Examples: 

#(CentrifugalPump.FlowRate)
#(TargetObject.LoopNumber)
#(@NNN)
#(Project.Name)
#(HotWaterPipe.LineNumber^@NNN)
#(TargetObject.Tag) - #(=TargetObject.Tag)
