Identifiers

 
 
 

Within an individual drawing file, all database-resident objects have an identifier (ObjectId, AcDbObjectId) that is unique to that object. Using an ObjectId to acquire an entity is a familiar and frequent activity for AutoCAD developers.

In standard ObjectARX, an ObjectId is unique only within the scope of a single drawing.

PnPID

Plant SDK introduces two additional identifiers. These IDs are unique at the project level, which may contain multiple drawings. The drawing object identifier (PpObjectId, AcPpObjectId) supports uniqueness among multiple drawings within a project.

A database record is maintained for every logical item represented by P&ID schematic. This integer identifier is the row ID and is visible to users in the Data Manager under the PnPID column.

The PpObjectId is a combination of the standard ObjectId and a drawing ID.

The PpRowId of a pipe or signal LineSegment is the same in every drawing that contains a portion of that pipe or signal line schematic. A single pipeline can be represented by multiple LineSegments in a drawing, and that pipeline can span multiple drawings. Each LineSegment has the same PpRowId, because it represents the same logical object.
