Introduction

 
 
 

The AutoCAD Plant 3D Application Programming Interface (API) extends the AutoCAD API to provide software developers with a means to query and control Plant Projects, P&ID drawings, and the 3D model.

Support and Requirements

The Plant 3D Software Developer Kit (SDK) supports interfaces for objects created with and stored in drawing (DWG) files using AutoCAD Plant 3D and legacy installations of AutoCAD P&ID.

The Plant 3D SDK is supported primarily through .NET managed assemblies. Unmanaged support is provided though for drawing object (AcDb) classes, but unmanaged access is limited otherwise. To access the managed libraries from unmanaged code, you can use common language runtime compilation. For more information, see the C++ interop sample.

NOTE:To successfully utilize the APIs documented in this guide, developers should be familiar with ObjectARX or the .NET managed wrappers for ObjectARX.

What's New

The following outlines the changes made to the Plant 3D SDK.

New in the SDK for 2024

Native API highlights

  • Changes to members used to create and update parts

Managed API highlights

  • New class and members related to exporting data to a MS Excel workbook
  • Updates to existing classes related to external references
New in the SDK for 2023

Native API highlights

  • New functions used to validate the characters in a string
  • Function that can be used to determine if a layout is currently being switched

Managed API highlights

  • New class and members related to base table callbacks for repositories
  • New members related to synchronizing changes to a project
New in the SDK for 2022

Native API highlights

  • New function for copying styles
  • New coordinate system functions related to ortho annotation

Managed API highlights

  • New compare and merge functionality added to project related classes
  • Several classes updated to support the checking of equality
New in the SDK for 2021

Native API highlights

  • 3D parts now participate in the AutoCAD AUDIT command

Managed API highlights

  • Improvements made to Ortho projects to support the copying and checking of symbols
New in the SDK for 2020

Native API highlights

  • Changes were made to some members that return the class name of an object

Managed API highlights

  • Minor changes related to Painter styles
  • Support was added for high resolution monitors
New in the SDK for 2019

Native API highlights

  • Get the class name of an Instrument now
  • Minor changes to the ability to set color of an Asset and a Line Segment

Managed API highlights

  • Improvements made to opening and creating databases
  • Events added related to the download progress of a project
  • Get children files by name now
  • Functions added to rename files
New in the SDK for 2018

Native API highlights

  • Minor improvements to the Specification Manager

Managed API highlights

  • DocumentServer now supports both, Vault and Collaboration (Cloud-based projects)
New in the SDK for 2017

Starting with this release, 32-bit support is no longer available.

Native API highlights

  • Connection Manager updated to support pipe to bend without weld
  • Ability to override the graphics for an asset and pipe segment

Managed API highlights

  • Primary focus for API changes moving forward, minimal changes to the Native API
New in the SDK for 2016

New high-level APIs to create, connect, and modify equipment, piping, and pipe supports in the 3D Model.

  • PnIDGUIUtilMgd.dll
  • PnP3dACPUtils.dll
  • PnP3dPipeUI.dll
  • PnP3dMain.dll
  • PnP3dPipeUI.dll

The best way to learn how to use the new classes is to compile and load the new samples: Equipment, PipeRouting, PipeSupports.

New in the SDK for 2015

A new high-level P&ID API makes it much easier to create and connect P&ID objects.

Classes added to Autodesk.ProcessPower.PnIDObjects include:

  • AssetAdder
  • AssetUtil
  • LineSegmentAdder
  • PnIDStyleUtils

The best way to learn how to use the new classes is to compile and load the new sample: Create and Connect a P&ID SLINE.

New in the SDK for 2014

Support for improved off-page connections, synchronization, and Vault projects. Updated handling of line groups.

The CreatePipeline sample has been improved. Support for imperial to metric connections.

New in the SDK for 2013

You can now create and connect piping in the 3D model. Get started with the CreatePipeline sample that is included with the Plant SDK. For more information, see Create and Connect Piping.

In this help guide, the Data Manager chapter has been updated. Code snippets now illustrate working with data objects and relationships for the Plant 3D model.
