Project Manager

 
 
 

Project details are configured with the Project class in the Autodesk.PrcessPower.ProjectManager namespace.

AutoCAD P&ID can have one project loaded at a time. To obtain a Project object, use PlantApplication.CurrentProject. PlantApplication is a singleton.

Below is sample code that obtains the current P&ID Project from PlantProject, then lists all of the drawings that are contained in the Project. 

//C# Code
using AcadApp = Autodesk.AutoCAD.ApplicationServices.Application;
using Autodesk.ProcessPower.ProjectManager;
using Autodesk.ProcessPower.PlantInstance;
[CommandMethod("LISTDWGS", CommandFlags.Modal)]
public static void ListProjectDrawings()
{
   Editor oEditor =    AcadApp.DocumentManager.MdiActiveDocument.Editor;
   ProjectPartCollection oPP =    PlantApplication.CurrentProject.ProjectParts;
   foreach (Project oPrj in oPP)
   {
      string strMsg = "\n" + oPrj.ProjectDirectory;
      oEditor.WriteMessage(strMsg);
      List<PnPProjectDrawing> oDwgList = oPrj.GetPnPDrawingFiles();
      foreach (PnPProjectDrawing oDwg in oDwgList)
      {
         strMsg = "\n    " + oDwg.AbsoluteFileName;
         oEditor.WriteMessage(strMsg);
      }
   }
}

When running a built-in command from AutoCAD P&ID such as sline, if the current drawing is not in the current project, the command stops and displays the message Operation canceled: disallowed in current project. P&ID built-in commands give users the option to either add the current drawing to the active project, or to Enter name of project to open.

The code sample below obtains the current project, if the active drawing is part of the project.

NOTE:When working with both drawing information and the Project Manager, a common task for developers is to ensure that the active drawing belongs to the current project. The PnPActiveProject function above may be useful as command prologue code in that situation.

Sample code in this guide uses PnPActiveProject to verify that the Active drawing is in the Current Project, and to obtain the current Project object.

The sample code below attempts to load the project with an assumed project name if the active drawing is not part of the current project. 

//C#
{
   Project oPnPDwgProject = PnPActiveProject();
   if (oPnPDwgProject != null) return;
   
   //Try to get the project from he drawing directory.
   //  This assumes that the Project and the Drawing file are in the same folder.
   Database oDwg = AcadApp.DocumentManager.MdiActiveDocument.Database;
   string sFolder = oDwg.OriginalFileName;
   string sProject = Path.Combine(Path.GetDirectoryName(sFolder), "Project.xml");
   oPnPDwgProject = PlantProject.LoadProject(sProject);
}
