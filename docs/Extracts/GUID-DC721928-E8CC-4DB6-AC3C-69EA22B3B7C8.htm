Getting Started

 
 
 

The Plant SDK Developer API extends the AutoCAD API. Plant-specific features are available as extensions to ObjectARX and the AutoCAD Managed Classes.

Microsoft® Visual Studio® 2022 version 17.2.6 is required.

Plant-specific features are not available to VBA, AutoLISP, or COM. AutoLISP (entmod) and (entmake) functions are not supported for P&ID entities.

NOTE:The Plant SDK requires the AutoCAD 2024 ObjectARX SDK. You can find the AutoCAD 2024 ObjectARX SDK at https://www.autodesk.com/developer-network/platform-technologies/autocad.

Microsoft Visual Studio requirements and setup are described in ObjectARX Introductory Concepts > Overview of ObjectARX > Getting Started from the ObjectARX Developer’s Guide (arxdev.chm).

Installation and Setup

Download and install the Plant SDK. Copy the Plant SDK files to the ObjectARX folder, which is C:\ObjectARX\ by default. The Plant SDK files share existing ObjectARX folders, but no files are overwritten.

The inc subdirectory contains unmanaged class declarations. The lib-x64 subdirectory contain the import library files (for example: PnPSharedUtilDLL.lib, AcPnpDataLinks.lib, and PnIDObjects.lib).

Class library (.dll) files (for example: PnIDMgd.dll, PnPDataLinks.dll, PnPProjectManagerMgd.dll, and PnPDataObjects.dll) are .NET managed assemblies. The assemblies are located in the inc-x64 folder.

NOTE:Starting with AutoCAD Plant 3D 2017, 32-bit support is no longer available.

The Plant SDK 2024: Developer Reference (plantsdk_ref.chm) documents class details and identifies the header file or assembly used for each class.
