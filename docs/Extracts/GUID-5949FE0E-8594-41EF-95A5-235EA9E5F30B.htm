Data Cache Relationships

 
 
 

The project data cache is managed through theDataLinksManager (managed)AcPpDataLinksManager (unmanaged) class. This data cache is a database containing information for all drawings in the project. The information is visible in the Data Manager within the product, although by default, it is filtered to display the information in the current drawing only. The relationships between P&ID objects are not visible.

The project data cache is a project-level database that tracks all Plant objects, their non-graphical properties, and the relationships between the objects.

Relationships are maintained in the data cache as the drawings in the project are edited.
