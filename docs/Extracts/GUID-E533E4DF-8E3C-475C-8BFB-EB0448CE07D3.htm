AcDbObject to PnID Database Link

 
 
 

The PnPDataLinks table can be used to acquire links between RowIDs in the database and drawing objects. This can be a one to many relationship and can also involve multiple drawings. For example, an SLINE that has been connected to another drawing using an offpage connector has a single RowID in the PipeLineGroup table and multiple entries in the DwgId table.

To create a link between a drawing-resident AcDb object (AcDbObjectId) and a database object (AcPpRowId): 

//C++
AcDbObjectId objId; AcPpRowId nRowId;
//Initialize objId and nRowID (not shown)
   
AcPpDataLinksManager *pLm = getCurrentDataLinksManager();
EPpDLStatus dlStat;
dlStat = pLm->Link (objId, nRowId);

To unlink: 

//C++
AcDbObjectId objId; AcPpRowId nRowId;
//Initialize objId (not shown)
   
AcPpDataLinksManager *pLm = getCurrentDataLinksManager();
EPpDLStatus dlStat;
bool bDeleteRow = false;
dlStat = pLm->Unlink(objId, bDeleteRow);
NOTE:If the bDeleteRow parameter of the Datalinks Manager’s Unlink method is true, the row is purged from the database. This causes all other row references in the project to unlink as well.
