Data Manager

 
 
 

Tagging and Catalog data can be programmatically acquired and maintained using the API. Connectivity and flow information for P&ID items can be analyzed by programs using an interface to the project database that maintains roles and relationships.

Most objects have a PnPID that identifies them at the project level as a logical item. A database record is maintained for every PnPID identifier, which is also known as the row ID (PpRowId, AcPpRowId).

The Datalinks manager (ProcessPower.DataLinks) allows developers to convert drawing-level (ObjectId, AcDbObjectId) identifiers into project level (PpObjectId, AcPpObjectId) identifiers.

The Data Objects (ProcessPower.DataObjects) interface provides a means to extend object properties from external data. Developers may add custom properties so that they appear on the Data Manager interface.

The DataObjects API is available only as a managed interface.
