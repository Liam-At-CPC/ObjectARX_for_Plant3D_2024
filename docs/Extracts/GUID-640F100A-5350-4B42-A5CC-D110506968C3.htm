Drawing Entities and Objects

 
 
 
NOTE:This chapter documents both the managed and unmanaged classes simultaneously. Class names are identified as (ManagedClass, UnmanagedClass).

P&ID entities are either equipment assets (Asset, AcPpAsset), or line segments (LineSegment, AcPpLineSegment). All other P&ID database resident objects are nonentity objects such as asset styles (AssetStyle, that reside in a dictionary.

Managed drawing-resident DBObject classes reference the PnIdMgd.dll or PnP3dObjects.dll .NET assembly in the inc-x64 folder.

NOTE:Starting with AutoCAD Plant 3D 2017, 32-bit support is no longer available.

Unmanaged ObjectARX AcDbObject items are defined in the AcPp header files in the inc folder.
