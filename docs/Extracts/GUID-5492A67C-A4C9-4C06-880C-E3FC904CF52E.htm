Set or Change Project File Locations

 
 
 

Project includes the methods to configure project file locations.

Directory paths that can be changed include:

  • Symbol library location – SymbolsDirectory
  • Report library location – ReportQueriesDirectory
  • Assemblies location – AssembliesDirectory

Project files that can be changed include:

  • Class schema (information about the class, or type, of components tracked in this project) – ClassSchemaFile
  • Project symbols and styles – SymbolAndStyleCacheFile
  • Drawing template (DWT) file – DwtTemplateFile

The following sample sets the default template file to be used when adding new drawings to the project. 

// C#
{
   Project oProject = PnPActiveProject();
   if (oProject == null) return;
   oProject.DwtTemplateFile = "PID ANSI E -Color Dependent Plot Styles.dwt";
   oProject.Save();
}

Project information is stored in the project.xml file with Project.Save. Changes made to a Project variable will not persist unless saved.
