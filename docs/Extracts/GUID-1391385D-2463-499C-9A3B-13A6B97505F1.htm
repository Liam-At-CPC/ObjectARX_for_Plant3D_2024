Schematic Lines

 
 
 

P&ID SLINE entities are similar to lightweight polylines. The appearance of an SLINE is defined by a reference to a Line Style. The Line Style is defined at the project level, so appearance changes made in one drawing propagate throughout the project.

Groups in standard AutoCAD can be created and edited under direct user control. With AutoCAD P&ID, line groups are automatically maintained. Using the SDK, developers are provided access to control line groups.
