Data Objects

 
 
 

Using ProcessPower.DataObjects, developers may query and extend the non-graphical properties in the Data Manager. PnPDataObjects.dll defines Data Object classes including PnPDatabase, PnPTable, PnPColumn, and PnPRow.

The following .NET managed code gets the Piping (3D Model) database from the project. It then selects and lists rows from a table. 

//C#
//using Autodesk.ProcessPower.PlantInstance;
//using Autodesk.ProcessPower.ProjectManager;
//using Autodesk.ProcessPower.DataLinks;
//using Autodesk.ProcessPower.DataObjects;

PlantProject objPlantProject = PlantApplication.CurrentProject;
Project prj = objPlantProject.ProjectParts["Piping"];
DataLinksManager dlm = prj.DataLinksManager;
PnPDatabase db = dlm.GetPnPDatabase();

PnPRowIdArray ids = null;
PnPTable ctab = db.Tables["PipeRunComponent"];
PnPRow [] rows = ctab.Select (null, ids);
//Tables.Rows returns only in-memory rows pending commit.

dumpRows(rows);

NOTE:Beginning with Plant SDK 2012, the PnPTable Rows property contains only data pending commit. To reduce memory consumption, it no longer contains data for the entire table. Use the Select method to obtain table data.

The following utility functions gets a named property (column) value from a PnPRow. 

object getRowVal(PnPRow row, string sColName)
{
        foreach (PnPColumn c in row.Table.AllColumns)
        {
            object val = row[c];
            if (c.Name == sColName) return val;
        }
        return null;
}

The following utility function lists all values in a PnPRow array. 

void dumpRows(PnPRow[] rows)
{
    foreach (PnPRow r in rows)
    {
        dumpRow(r);
    }
}

void dumpRow(PnPRow r)
{
    Editor ed = Application.DocumentManager.MdiActiveDocument.Editor;
    ed.WriteMessage("\n   ");
    //For every column in the row list the value.
    foreach (PnPColumn c in r.Table.AllColumns)
    {
        object val = r[c];
        ed.WriteMessage(string.Format("{0}={1} ", c.Name, val));
    }
}

The following code lists all table names in a database 

public void ListTables() // This method can have any name
{
    Project prj = PnPProjectUtils.GetProjectPartForCurrentDocument();
    DataLinksManager dlm = prj.DataLinksManager;
    PnPDatabase db = dlm.GetPnPDatabase();
    foreach (PnPTable tb in db.Tables)
    {
        Editor ed = Application.DocumentManager.MdiActiveDocument.Editor;
        ed.WriteMessage("\n" + tb.Name);
    }
}
