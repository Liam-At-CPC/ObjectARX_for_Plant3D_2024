Line Objects

 
 
 

AcPpLineObjects are utility constructs that provide developers with a means to analyze sline connectivity in a flow iterative, segmented manner.

An AcPpLineObject is collected by gathering an AcPpLineObjectIterator from AcPpLineSegment::lineObjectIterator. You may step through the iterator to access AcPpLineObjects.

Line Objects can be used to modify line segments. For example, you can remove an AcPpInlineGap by calling AcPpLineSegment::RemoveLineObject.

NOTE:Line Objects are not drawing entities and do not reside in the drawing database. They are utility objects used to identify sline segments, gaps, intersections, attached assets, and connected slines.

The following are AcPpLineObjects:

  • AcPpEndlineObject - Asset or segment at the Start or End of the line.
  • AcPpInlineEntity - All other assets or segments that are not Endline.
  • AcPpInlineGap - An explicit, manually created usergap.
  • AcPpInlineIntersection - Implied gaps, as from an intersection.

The following code sample selects an sline, then lists the type and location of each line object on the chosen sline. 

//C#
using Autodesk.AutoCAD.ApplicationServices;
using Autodesk.AutoCAD.EditorInput;
using Autodesk.AutoCAD.DatabaseServices;
using Autodesk.ProcessPower.PnIDObjects;
{
   Editor ed = Application.DocumentManager.MdiActiveDocument.Editor;
   Database db = Application.DocumentManager.MdiActiveDocument.Database;
   ObjectId entId = ed.GetEntity("Pick an SLINE: ").ObjectId;
   if (entId.IsNull) return;
   Autodesk.AutoCAD.DatabaseServices.TransactionManager tm = db.TransactionManager;
   using (Transaction tr = tm.StartTransaction())
   {
      Entity entity = (Entity)tm.GetObject(entId, OpenMode.ForRead);
      LineSegment sline = entity as LineSegment;
      if (sline == null) return;
      LineObjectCollection colLineObj = sline.GetLineObjectCollection(null);
      foreach (LineObject lo in colLineObj)
      {
         ed.WriteMessage("\nSegment " + lo.SegmentIndex + ": " + lo.GetType() + ", " + lo.Position);
      }
   }
}

The following code would list the ClassName of all Asset items on the line. 

//C#
foreach (LineObject lo in colLineObj)
{
   if (lo is InlineEntity) {
      InlineEntity loInlineEntity = (InlineEntity)lo;
      Entity entityLo = (Entity)tm.GetObject(loInlineEntity.ObjectId, OpenMode.ForRead);
      if (entityLo is Asset) {
         Asset assetLo = (Asset)entityLo;
         ed.WriteMessage ("\nConnected to (" + assetLo.ClassName +").");
      }
   }
}
