PnID Data Properties

 
 
 

Once an item is linked to the database, the Datalinks Manager can be used to retrieve and update data as properties of the PnID entity. The following code recovers manufacturer properties for all data-linked P&ID items in a drawing: 

//C#
Database db = Application.DocumentManager.MdiActiveDocument.Database;
DataLinksManager dlm = DataLinksManager.GetManager(db);
PnPRowIdArray aPid = dlm.SelectAcPpRowIds(db);
foreach (int rid in aPid) {
   StringCollection sKeys = new StringCollection();
   sKeys.Add("Manufacturer");
   sKeys.Add("ModelNumber");
   sKeys.Add("Description");
   StringCollection sVals = dlm.GetProperties(rid, sKeys, true);
   ed.WriteMessage("\n" + sVals[1] + " (" + sVals[0]+ ") " + sVals[2] + ".");
}
